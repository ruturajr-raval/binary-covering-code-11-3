# Third-Word Child Frontier

The stage-1 residual contains 49 canonical two-word parents. Splitting each
parent by the first occupied orbit of a third selected word gives 3,238
canonical child branches.

The advanced case ledger classifies those children as follows:

| Classification point | Parents | Child orbits |
| --- | ---: | ---: |
| Stage-1 third-word universe | 49 | 3,238 |
| Parents closed by checked third-word DRAT | 6 | 423 |
| Remaining after those DRAT closures | 43 | 2,815 |
| Parents closed by maximum-degree contradiction | 5 | 267 |
| Children below the 38 active parents | 38 | 2,548 |
| Excluded by existing minimum-distance clauses | 38 | 312 |
| Additionally excluded by the matching theorem | 30 | 73 |
| Live child frontier | 38 | 2,163 |

The figure 2,815 is therefore an intermediate non-DRAT count. It includes the
267 child orbits below five parents that are already closed by the
maximum-degree theorem. The 38 active parents contain 2,548 raw child orbits.
Of these, 312 violate the already imposed minimum-distance clauses and 73 more
violate the certified matching condition. Exactly 2,163 children survive all
currently retained static constraints. Every active parent retains at least
28 live children.

## Manifest

`research/third-word-child-frontier.json` retains every one of the 3,238
stage-1 children. Parent records use three statuses:

- `active`
- `closed_maximum_degree`
- `closed_third_word_drat`

Children below active parents are then classified as:

- `live`
- `excluded_minimum_distance`
- `excluded_matching`

Each child records its stable identifier, parent-local orbit index, dense live
index when applicable, four-cell descriptor, canonical word, orbit size,
fixed-word distances, imposed unit constraints, static exclusion reason, and
SHA-256 identity digest. Parent records authenticate their child lists and
link the exact minimum-distance formula, parent-unit digest, orbit digest,
matching scope, and closure evidence.

The live index is dense from 0 through 2,162. The active-parent index is dense
from 0 through 2,547 and includes the 385 static exclusions. The non-DRAT
index is dense from 0 through 2,814 and intentionally includes the
maximum-degree closures.

## Independent Audit

The generator projects the already audited stage-1 orbit manifest onto the
advanced case ledger.

The auditor does not import the generator or the shared third-word symmetry
module. It independently:

1. enumerates all 2,048 ambient words for each stage-1 parent;
2. applies the parent threshold directly;
3. groups candidates by the four stabilizer-cell intersection counts;
4. chooses the least integer in each orbit as its canonical word;
5. reconstructs all child identifiers, indices, and digests;
6. recomputes every maximum-degree classification from the parent data;
7. re-evaluates the minimum-distance and matching exclusions from fixed-word
   distances;
8. authenticates every retained formula-metadata, proof, summary, and
   proof-check file by SHA-256 digest and checks the recorded formula digest;
9. verifies matching assumptions are used only within their certified scope;
10. verifies the semantic metadata and the disjoint status cover.

Audit the retained manifest without rewriting it:

```text
make audit-third-word-child-frontier
```

Regenerate it and then audit the regenerated bytes:

```text
make rebuild-and-audit-third-word-child-frontier
```

The audit accepts only the exact counts and content digests stated above.
